# 🛒 Sample E-Commerce Website

This is a simple **e-commerce website** built using **HTML, CSS, and JavaScript**.  
It demonstrates the basics of product listing, adding items to a cart, removing them, and calculating totals — all without a backend.

---

## 🚀 Features
- Display products with **image, name, and price**
- Add items to the cart
- Remove items from the cart
- Shows **cart item count** and **total price**
- Simple and clean **responsive layout**
